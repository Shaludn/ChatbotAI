# ChatbotAI

A smart AI-powered chatbot web application that supports real-time chatting, mathematical calculations, and AI-generated responses using OpenRouter API integration.

## Features

- **AI Chat Support**: Get intelligent responses using OpenRouter AI models
- **Math Solver**: Solve mathematical expressions instantly
- **Real-Time Messaging**: Interactive chatbot interface with instant replies
- **Modern UI Design**: Clean and responsive chatbot interface
- **Keyboard Support**: Send messages using the Enter key
- **Servlet-Based Backend**: Built using Java Servlets and Apache Tomcat
- **Responsive Design**: Works smoothly on desktop and laptop devices
